## What changed (all pages)
- **One stylesheet for the whole JOS:** `assets/w2w-v3.css` — Onest (self-hosted woff2, no Google Fonts), W2W v3 tokens (light + dark),
  JOS aliases (`--mint → --brand` turquoise, `--ok` = green **only** as a status signal), Liquid-Glass primitives (`.lg`, `.v3-tabs`,
  `.v3-select`, `.v3-menu`, `.segmented`, `.switch`). Every template links it; the shell's `<style>` ends with a «W2W v3» override block that
  panels inherit via `jos_css()`.
- **Panels have a real dark theme** (`html[data-theme]` from `localStorage.jos-theme`, pushed by the shell into every iframe). The old
  `filter:invert()` on `iframe.panel` is gone, so photos, brand colours and the embedded CRM look right in both themes.
- **Less text, calmer controls:** sidebar + mobile bar use line icons instead of emoji; leading emoji are stripped from headings, tabs,
  buttons and pills after every render (shell and panels); top-bar actions (export / reset / language / theme on phones) sit behind «⋯»;
  tabs are underline tabs; filters are dropdowns (sales stages, files machine/type/project, products kind); file rows = name + one meta
  line, path and actions on click; leads/marketing/files intro texts shortened.
- Phone: top bar is one row (menu · title · archive · edit · ⋯), glass bottom bar, 38 px touch targets, no horizontal page scroll.
